Agent Zero 项目的代码风格和约定如下：

*   **PEP 8 遵循：** 普遍遵循 Python 的 PEP 8 风格指南，包括变量名和函数名使用 `snake_case`，类名使用 `CamelCase`。
*   **类型提示：** 代码中广泛使用了类型提示，以提高可读性和维护性。
*   **Docstrings/注释：** 函数和类通常包含 docstrings 来解释其目的和用法。复杂逻辑旁边有内联注释。
*   **模块化：** 项目结构良好，文件和目录按功能模块化，例如 `helpers/` 和 `tools/`。
*   **异常处理：** 使用 `try-except` 块进行错误处理。
*   **常量命名：** 常量使用全大写和下划线命名（例如 `HEADING_MAX_LEN`）。
