# 项目架构设计图

本报告通过 Mermaid 图展示 Agent Zero 项目中核心组件及其相互关系。

```mermaid
graph TD
    A[User/Agent Zero] --> B{Instruction/Task};

    B --> C{Agent Core Logic<br/><Decision, Planning>};
    
    C --> D[Prompts<br/><prompts/>];
    D --> C;
    %% Prompts influence Agent Logic

    C --> E[Memory System<br/><python/helpers/memory.py>];
    E --> C;
    %% Memory System provides context

    C --> F[Knowledge Base<br/><knowledge/<br/>python/helpers/document_query.py>];
    F --> C;
    %% Knowledge Base provides information

    C --> G{Tool Call<br/><python/tools/>};
    G --> H[Code Execution Tool];
    G --> I[Memory Tools];
    G --> J[Document Query Tool];
    G --> K[Search Engine Tool];
    G --> L[Browser Agent Tool];
    G --> M[Scheduler Tool];

    G --> C;
    %% Tool execution results return to Agent

    C --> N{Subordinate Agents};
    N --> C;
    %% Subordinate Agent results return to superior agent

    C --> O[Extensions<br/><python/extensions/>];
    O --> C;
    %% Extensions influence Agent message flow

    A --> P[Web UI];
    P --> Q[API<br/><python/api/>];
    Q --> C;
    %% Web UI interacts with Agent Core Logic via API

    subgraph Core Flow
        B --> C;
        C --> G;
        G --> C;
        C --> N;
        N --> C;
    end

    subgraph Supporting Systems
        D;
        E;
        F;
        O;
        P;
        Q;
    end

    classDef default fill:#f9f,stroke:#333,stroke-width:2px;
    classDef tool fill:#bbf,stroke:#333,stroke-width:2px;
    classDef system fill:#bfb,stroke:#333,stroke-width:2px;
    classDef input_output fill:#fdd,stroke:#333,stroke-width:2px;

    class C,G,N,Q default;
    class H,I,J,K,L,M tool;
    class D,E,F,O system;
    class B input_output;
    class A,P input_output;
