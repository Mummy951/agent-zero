# Agent Zero 项目大致说明

## 1. 项目概要

Agent Zero 是一个个人化的、有机成长的智能代理框架，旨在动态学习并随用户使用而不断发展。它并非预设用于特定任务，而是作为一个通用型个人助理。用户可以向它分配任务，它会自主收集信息、执行命令和代码、与其他代理实例协作，并尽力完成任务。

Agent Zero 的核心理念是“计算机即工具”，它利用操作系统作为工具来完成任务，而不是预设单用途工具。它能够自行编写代码并使用终端创建和使用所需的工具。其唯一默认工具集包括在线搜索、记忆功能、通信（与用户及其他代理）以及代码/终端执行。

该框架高度透明、可读、可理解、可定制和交互。几乎所有行为都通过 [`prompts/default/agent.system.md`](prompts/default/agent.system.md) 文件中的系统提示定义，用户可以根据需求进行修改和扩展。

## 2. 技术特色

### 2.1 动态学习与成长
- **非预设代理框架：** Agent Zero 并非针对特定任务进行预编程，它会随着使用而动态成长和学习。
- **持久化记忆：** 具备持久化记忆功能，能够记忆之前的解决方案、代码、事实、指令等，以便未来更快、更可靠地解决问题。

### 2.2 计算机即工具
- **操作系统作为工具：** Agent Zero 将操作系统作为工具，能够编写自己的代码并通过终端创建和使用工具。
- **默认工具：** 内置在线搜索、记忆、通信和代码/终端执行工具。其他所有工具都可由代理自行创建或由用户扩展。
- **工具兼容性：** 从头开发了工具使用功能，即使对于小型模型也具有高度兼容性和可靠性。
- **自定义工具与 Instruments：** 支持创建自定义工具，Instruments 是一种新型工具，允许创建自定义函数和过程，Agent Zero 可以调用它们。

### 2.3 多代理协作
- **层级代理结构：** 每个代理都有一个上级代理分配任务和指令，并向上级汇报。Agent 0 的上级是人类用户。
- **子代理委托：** 每个代理都可以创建子代理来分解和解决子任务，保持上下文清晰和专注。

### 2.4 完全可定制和可扩展
- **无硬编码：** 框架中几乎没有硬编码，所有内容都可以由用户扩展或更改。
- **提示驱动行为：** 通过 [`prompts/default/agent.system.md`](prompts/default/agent.system.md) 中的系统提示定义代理的整体行为。
- **可修改的通信模板：** [`prompts/`](prompts/) 文件夹中包含所有用于代理通信循环的提示和消息模板，均可修改。
- **可修改的内置工具：** [`python/tools/`](python/tools/) 文件夹中包含所有内置工具的实现，可以更改或复制以创建新的预定义工具。

### 2.5 强大的沟通能力
- **实时交互：** 终端界面实时流式传输且具有交互性，用户可以随时停止和干预。
- **系统提示指导：** 可以通过系统提示指导代理有效沟通，包括定期汇报、请求许可、使用评分系统等。

### 2.6 全面 Docker 化，支持语音转文本和文本转语音
- **Docker 化：** 完全 Docker 化，确保跨平台的一致性、简化部署和更新、通过容器化增强安全性。
- **Web UI：** 清晰、流畅、色彩丰富、可读且交互性强的 Web UI 输出，所有信息都可见。
- **聊天管理：** 支持在 Web UI 中直接加载或保存聊天。
- **日志记录：** 终端输出会自动保存为 HTML 文件在 `logs/` 文件夹中。
- **实时流式输出：** 代理输出实时流式传输，用户可以随时阅读和干预。
- **语音接口：** 提供文本转语音（TTS）和语音转文本（STT）功能，支持自然语音交互。

## 3. 技术栈
- **主要编程语言：** Python
- **容器化：** Docker
- **Web 框架：** Flask (用于 API 端点)
- **前端技术：** HTML, CSS, JavaScript (用于 Web UI)
- **文档：** Markdown
- **搜索：** SearXNG (替代 Perplexity + DuckDuckGo)
- **LLM 框架：** LiteLLM (替代 Langchain，支持更多模型提供商和推理模型流式传输)
- **语音技术：** OpenAI's Whisper 模型 (STT), 系统内置语音合成器 (TTS)
- **数学排版：** KaTeX
- **版本控制：** Git (用于版本检测)
- **虚拟环境管理：** Conda (推荐用于本地完整二进制安装)

## 4. 依赖管理工具
- **Python 依赖：** [`requirements.txt`](requirements.txt) (通过 `pip install -r requirements.txt` 安装)
- **系统工具：** Docker (用于容器化部署和运行环境)
- **其他：** `pathspec` (用于 glob 模式匹配), `psutil` (用于系统信息收集)

    - [`python/tools/memory_forget.py`](python/tools/memory_forget.py), [`memory_load.py`](python/tools/memory_load.py), [`memory_save.py`](python/tools/memory_save.py): 记忆管理工具。

  - **[`webui/components/`](webui/components/)：** 构成 Web UI 的各种组件。

- **[`instruments/`](instruments/)：** 包含 Agent Zero 可以使用的自定义工具或功能的定义。

## 7. 配置部署方式

Agent Zero 主要推荐通过 Docker 进行部署，也支持在主机系统上直接运行（完整二进制安装），但需要手动配置。

### 7.1 Docker 部署 (推荐)

- **环境准备：** 安装 Docker Desktop。
- **拉取镜像：** `docker pull agent0ai/agent-zero`
- **运行容器：** `docker run -p $PORT:80 -v /path/to/your/data:/a0 agent0ai/agent-zero`
  - `$PORT`：希望使用的端口。
  - `/path/to/your/data`：本地机器上用于存储 Agent Zero 数据的目录，这将挂载到容器内的 `/a0` 目录，实现数据持久化。
- **访问 Web UI：** 浏览器访问 `http://localhost:$PORT`。
- **优势：** 跨平台一致性、简化部署更新、增强安全性、减少主机系统依赖。

### 7.2 完整二进制安装 (面向开发者/贡献者)

- **环境准备：** 安装 Conda (miniconda) 用于管理 Python 环境。
- **下载代码：** 从 GitHub 克隆或下载 Agent Zero 仓库。
- **设置 Conda 环境：**
  1. `conda create -n a0 python=3.12 -y`
  2. `conda activate a0`
  3. `pip install -r requirements.txt`
- **安装 Docker (本地连接)：** 即使是完整二进制安装，Agent Zero 仍需要连接到 Docker 容器来执行代码和命令。需要安装 Docker Desktop 并确保配置了 Docker socket 访问。
- **运行本地实例：** 在激活的 Conda 环境中运行 `python run_ui.py`。
- **配置 RFC：** 在本地实例和 Docker 实例的 Web UI 设置中配置远程函数调用 (RFC) 参数，将一些功能重定向到 Docker 容器。

### 7.3 设置配置

Agent Zero 提供全面的设置界面来定制其功能，可通过 Web UI 访问。

- **代理配置：** 选择提示子目录、记忆子目录、知识子目录。
- **聊天模型设置：** 选择 LLM 提供商 (如 Ollama)、模型名称、温度、上下文长度等。
- **实用模型配置：** 为内存组织和摘要等实用任务选择较小、较快的模型。
- **嵌入模型设置：** 选择嵌入模型提供商和模型名称。更改嵌入模型会重新索引所有记忆和知识。
- **语音转文本选项：** 配置语音识别模型大小、语言代码和静音设置。
- **API 密钥：** 在 Web UI 中配置各种服务提供商的 API 密钥。
- **身份验证：** 设置 Web 界面访问的用户名和密码，以及 Docker 容器 root 密码 (用于 SSH 访问)。
- **开发设置：** 配置 RFC 参数 (仅本地实例)。

## 8. 各项功能的最佳实践教程 (一步一步的操作教程)

以下从已阅读的文档中提炼出的各项功能最佳实践：

### 8.1 安装与更新

1.  **安装 Docker Desktop**：访问 Docker 官网下载并安装适用于您操作系统的 Docker Desktop。
2.  **拉取 Agent Zero Docker 镜像**：在终端运行 `docker pull agent0ai/agent-zero`。
3.  **创建数据目录**：选择或创建一个目录（例如 `C:/agent-zero-data`）用于存储 Agent Zero 的数据，这将是 `/a0` 容器卷的挂载点。
4.  **运行容器**：
    -   **Docker Desktop UI**：在 Docker Desktop 的 "Images" 标签页中找到 `agent0ai/agent-zero` 镜像，点击 `Run`。
    -   在 "Optional settings" 中将第二个 "Host port" 设置为 `0` (自动分配端口)。
    -   在 "Volumes" 下，Host path 设置为您创建的数据目录，Container path 设置为 `/a0`。
    -   点击 `Run`。
    -   **终端命令**：`docker run -p $PORT:80 -v /path/to/your/data:/a0 agent0ai/agent-zero` (将 `$PORT` 和 `/path/to/your/data` 替换为您的设置)。
5.  **访问 Web UI**：在 Docker Desktop 的 "Containers" 标签页中找到运行中的容器，点击端口号 (例如 `32771:80`)，或者在浏览器中访问 `http://localhost:<PORT>`。

**更新 Agent Zero (Docker)**：
1.  **停止并移除旧容器**：在 Docker Desktop 的 "Containers" 标签页中停止并删除 Agent Zero 容器（数据会保留在您映射的本地数据目录中）。
2.  **移除旧镜像**：在 Docker Desktop 的 "Images" 标签页中移除 `agent0ai/agent-zero` 旧镜像。
3.  **拉取最新镜像并重新运行**：重复上述安装步骤，拉取最新镜像并使用相同的卷挂载路径运行新容器。

### 8.2 快速开始 (运行简单任务)

1.  **启动 Web UI**：在 Agent Zero 目录中激活 conda 环境（如果使用）并运行 `python run_ui.py`。
2.  **打开浏览器**：访问终端中显示的 URL（通常是 `http://127.0.0.1:50001`）。
3.  **输入任务**：在聊天输入框中输入任务，例如 "Download a YouTube video for me"（为我下载一个 YouTube 视频），然后按回车或点击发送按钮。
4.  **观察代理执行**：您将看到代理的“思考”和它在 UI 中执行的操作。它会找到一个现有的解决方案，使用 `code_execution_tool` 运行 Python 脚本来执行任务。
5.  **提供信息**：代理会询问您要下载的 YouTube 视频 URL。

### 8.3 配置 LLMs (本地模型 Ollama)

1.  **安装 Ollama**：
    -   **Windows**：从 [Ollama 官网](https://ollama.com/download/OllamaSetup.exe) 下载并安装。
    -   **macOS**：`brew install ollama` 或从官网下载安装器。
    -   **Linux**：`curl -fsSL https://ollama.com/install.sh | sh`。
2.  **拉取模型**：在终端运行 `ollama pull <model-name>`（例如 `ollama pull mistral-large`）。
3.  **在 Agent Zero 中选择模型**：
    -   打开 Web UI 的 "Settings"（设置）页面。
    -   在 "Chat model"（聊天模型）、"Utility model"（实用模型）或 "Embedding model"（嵌入模型）部分，选择 "Ollama" 作为提供商。
    -   在模型名称字段中输入您拉取的模型代码（例如 `llama3.2` 或 `qwen2.5:7b`）。
    -   点击 `Save`（保存）确认设置。

### 8.4 工具使用 (Web 搜索和代码执行示例)

要让 Agent Zero 执行财务分析任务，例如查找上月比特币/美元价格趋势并制作图表：

1.  **给出提示**：在聊天中输入以下提示：
    > Please be a professional financial analyst. Find last month Bitcoin/ USD price trend and make a chart in your environment. The chart must have highlighted key points corresponding with dates of major news about cryptocurrency. Use the 'knowledge_tool' to find the price and the news, and the 'code_execution_tool' to perform the rest of the job.

2.  **代理执行**：Agent Zero 将会：
    -   使用 `knowledge_tool` 查询比特币价格和相关新闻。
    -   从搜索结果中提取价格并保存新闻，提取日期和潜在影响。
    -   使用 `code_execution_tool` 执行 Python 脚本，利用提取的数据和新闻日期创建图表并突出显示关键点。
    -   将最终图表保存到 `/work_dir` 目录，并使用 `response_tool` 向用户响应。

### 8.5 多代理协作

1.  **创建子代理**：Agent Zero 可以创建子代理来分解复杂任务并分配工作负载。
2.  **沟通协调**：代理之间通过系统提示和消息历史进行信息共享和行动协调。
3.  **层级结构**：利用其层级结构，上级代理可以向子代理委托任务，实现结构化的问题解决。

### 8.6 提示工程

-   **清晰具体**：明确说明您期望的结果。越具体，代理越能理解并满足您的请求。
-   **提供上下文**：如果需要，提供背景信息或上下文，帮助代理更好地理解任务。
-   **分解复杂任务**：将复杂任务分解为更小、更易管理子任务。
-   **迭代细化**：通过尝试不同提示，根据代理响应调整指令，直到达到预期结果。

### 8.7 语音接口

**文本转语音 (TTS)**：
1.  在侧边栏的 "Preferences"（偏好设置）部分切换 "Speech"（语音）开关。
2.  代理将使用您系统的内置语音合成器朗读消息。
3.  点击输入区域上方的 "Stop Speech"（停止语音）按钮可随时停止。

**语音转文本 (STT)**：
1.  点击输入区域的麦克风按钮开始录音。
2.  按钮颜色指示状态（灰色：非活动，红色：监听，绿色：录音，青色：等待，青色脉冲：处理）。
3.  在“设置”页面中配置 STT 设置，例如模型大小、语言代码和静音检测阈值。

### 8.8 文件浏览器

1.  **导航**：点击目录进入，使用 "Up"（向上）按钮返回上级目录。当前路径始终可见。
2.  **文件操作**：
    -   **创建**：创建新文件和目录。
    -   **删除**：删除现有文件和目录。
    -   **下载**：将文件下载到本地系统。
    -   **上传**：从本地系统上传文件。
3.  **管理**：在 Web UI 界面中直接上传、下载、删除文件和文件夹。
4.  **批量操作**：支持同时上传多个文件，并选择和管理多个文件。

### 8.9 备份与恢复

**创建备份**：
1.  访问 Web UI 的 "Settings"（设置）-> "Backup"（备份）标签页。
2.  点击 "Create Backup"（创建备份）。
3.  您可以自定义要包含的文件和文件夹模式，并预览将备份的文件。
4.  给备份起一个描述性名称，然后点击 "Create Backup" 生成 ZIP 归档。

**从备份恢复**：
1.  导航到 "Settings"（设置）-> "Backup"（备份）标签页。
2.  点击 "Restore from Backup"（从备份恢复）。
3.  上传您的备份 ZIP 文件。
4.  您可以审查并自定义恢复内容，包括选择性地恢复文件、处理文件冲突（覆盖、跳过或备份现有文件）。

### 8.10 隧道功能

1.  **打开设置**：在 Web UI 中打开“设置”并导航到“External Services”（外部服务）标签页。
2.  **选择 Flare Tunnel**：点击导航菜单中的“Flare Tunnel”。
3.  **创建隧道**：点击“Create Tunnel”（创建隧道）按钮生成一个新隧道。
4.  **共享 URL**：隧道 URL 将会显示，您可以复制并与他人共享。
5.  **添加认证**：为了安全，建议在 `AUTH_LOGIN` 和 `AUTH_PASSWORD` 环境变量中设置用户名和密码，或直接在设置界面配置。
