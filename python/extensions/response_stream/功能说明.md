# response_stream 扩展功能说明

## 功能概述
`response_stream` 扩展在代理主语言模型（LLM）生成响应并以流式方式传输时执行。其核心功能是实时地捕获、处理和显示LLM的输出，包括中间状态和最终响应，从而为用户提供一个动态且透明的交互体验。

## 详细功能
1. **日志流式更新 (`_10_log_from_stream.py`)**:
   - 此组件负责在LLM流式输出其响应时，实时创建或更新日志条目。
   - 它能解析LLM输出中的结构化信息（如`headline`、`tool_name`、`thoughts`等），并根据这些信息动态调整日志条目的标题。
   - 例如，如果LLM开始使用某个工具，日志标题会更新为“Using tool [工具名称]”；如果LLM正在思考，标题会显示“Thinking...”并伴随一个长度指示器。
   - 它还会将LLM流式输出的文本内容实时添加到日志中，确保日志与LLM的生成过程同步。

2. **实时响应显示 (`_20_live_response.py`)**:
   - 此组件专门用于从LLM的流式输出中识别并提取最终的用户可见响应文本。
   - 它会检查解析后的LLM输出是否包含一个明确的“响应”工具调用（`"tool_name": "response"`）及其`text`参数。
   - 一旦识别到有效的响应文本，它会将其更新到一个专门用于显示实时用户响应的日志项中，确保用户能够及时看到代理的最终回复。

## 用途
`response_stream` 扩展对于提供流畅和响应迅速的用户体验至关重要。通过实时处理和显示LLM的输出，它：
- **提高响应感知**: 用户可以立即看到代理正在生成回复或执行操作，减少等待感。
- **增强透明度**: 不仅显示最终答案，也显示LLM生成答案的过程，提升用户对代理的理解。
- **改善交互性**: 使得用户能够更快地理解代理的意图和进展。
- **辅助调试**: 对于开发者，它提供了LLM输出的详细视图，便于诊断问题和优化代理行为。
