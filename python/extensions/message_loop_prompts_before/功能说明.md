# message_loop_prompts_before 扩展功能说明

## 功能概述
`message_loop_prompts_before` 扩展在代理的消息循环中，将提示发送给主语言模型（LLM）之前执行。其核心功能是确保聊天历史已被适当地压缩和管理，以优化LLM处理提示的效率和避免上下文过载。

## 详细功能
1. **历史压缩等待 (`_90_organize_history_wait.py`)**:
   - 此组件负责在将提示传递给LLM之前，同步等待或强制执行聊天历史的压缩操作。
   - 它会检查代理的历史记录是否超过了预设的限制。
   - 如果存在正在进行的异步历史压缩任务，它会等待该任务完成。
   - 如果没有正在运行的历史压缩任务但历史记录已超限，它将启动一个新的压缩任务并等待其完成。
   - 这确保了LLM始终接收到经过优化的、大小受控的聊天历史上下文，从而提高LLM的响应效率和质量。

## 用途
`message_loop_prompts_before` 扩展是确保代理对话流畅性和效率的关键。通过在提示生成前管理历史上下文大小，它：
- **防止上下文溢出**: 避免将过长的历史记录发送给LLM，这可能导致API调用失败或不必要的成本增加。
- **提高LLM性能**: 优化LLM处理提示的速度和准确性，因为它不需要处理冗余或过多的历史信息。
- **确保及时处理**: 如果历史压缩是异步进行的，此扩展保证在LLM需要这些信息时，压缩操作已经完成。
