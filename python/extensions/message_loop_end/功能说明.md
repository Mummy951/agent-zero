# message_loop_end 扩展功能说明

## 功能概述
`message_loop_end` 扩展在代理的消息循环结束后执行。它主要负责处理聊天历史的组织和聊天会话的持久化，确保系统资源得到有效管理并保存用户数据。

## 详细功能
1. **历史记录组织 (`_10_organize_history.py`)**:
   - 此组件检查是否存在正在运行的历史记录组织任务。
   - 如果没有，它会启动一个异步任务来压缩或优化代理的聊天历史记录。这对于管理上下文大小、避免过载和提高性能至关重要。
   - 它确保历史记录的整理过程不会阻塞主消息循环，并在需要时等待其完成。
2. **聊天会话保存 (`_90_save_chat.py`)**:
   - 此组件负责将当前的聊天会话保存到持久存储中。
   - 它调用 `persist_chat.save_tmp_chat()` 来确保即使在系统关闭或崩溃的情况下，用户当前的聊天进度也不会丢失。

## 用途
`message_loop_end` 扩展对于维护代理的长期会话连贯性和数据完整性至关重要。它确保了聊天历史的有效管理，防止上下文膨胀，并提供了一个可靠的机制来保存用户和代理之间的所有交互。
