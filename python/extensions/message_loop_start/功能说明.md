# message_loop_start 扩展功能说明

## 功能概述
`message_loop_start` 扩展在代理的每个消息循环开始时执行。其主要功能是跟踪和管理消息循环的迭代次数，为代理提供一个内部的进度或状态计数器。

## 详细功能
1. **迭代次数计数 (`_10_iteration_no.py`)**:
   - 此组件负责在每次消息循环开始时递增一个内部计数器。
   - 计数器记录了代理处理当前任务所经历的循环总次数。
   - 迭代次数存储在代理的内部数据中，并通过 `get_iter_no` 函数对外提供访问接口。

## 用途
`message_loop_start` 扩展为代理提供了一个基本的迭代机制，这在许多场景中都非常有用，例如：
- **监控进度**: 允许代理或外部系统了解任务执行的步进情况。
- **控制逻辑**: 基于迭代次数实现某些条件判断或逻辑分支，例如在特定迭代次数后执行某个操作，或者在达到最大迭代次数时终止循环。
- **调试和分析**: 在调试代理行为或分析其性能时，迭代次数提供了重要的时间维度信息。
