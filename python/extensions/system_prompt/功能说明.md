# system_prompt 扩展功能说明

## 功能概述
`system_prompt` 扩展负责在代理与主语言模型（LLM）交互时，动态地构建和配置传递给LLM的“系统提示”（System Prompt）。系统提示为LLM提供关键的上下文信息、指令、可用工具和行为准则，以指导其生成适当的响应和执行任务。

## 详细功能
1. **核心系统提示生成 (`_10_system_prompt.py`)**:
   - 此组件负责整合代理的核心操作指令 (`agent.system.main.md`) 和通用的工具描述 (`agent.system.tools.md`)。
   - 如果LLM模型支持视觉能力（`agent.config.chat_model.vision`），还会额外添加视觉相关的工具描述 (`agent.system.tools_vision.md`)。
   - 如果配置了多客户端协议（MCP）服务器，它还会从MCP配置中收集并包含可用的MCP工具描述，这可能涉及一个动态的工具收集过程。
   - 所有这些内容被组合起来，形成LLM接收到的基础系统提示，指导其理解任务和可用的操作。

2. **行为规则提示插入 (`_20_behaviour_prompt.py`)**:
   - 此组件负责加载代理的行为规则。它首先尝试从一个自定义的行为规则文件（通常是存储在记忆目录下的 `behaviour.md`）中读取规则。
   - 如果自定义文件不存在，它将回退到加载默认的行为规则 (`agent.system.behaviour_default.md`)。
   - 这些行为规则（无论自定义还是默认）随后会被封装在 `agent.system.behaviour.md` 模板中，并插入到整个系统提示的最前端。这确保了代理的行为准则对LLM具有最高的优先级。

## 用途
`system_prompt` 扩展对于确保代理能够正确理解其角色、可用的功能以及应遵循的行为规范至关重要。通过动态地构建系统提示，它使得代理能够：
- **准确执行任务**: LLM接收到清晰的指令和工具描述，知道如何响应和利用外部能力。
- **保持一致的行为**: 行为规则确保了代理在不同情境下保持预期的响应风格和决策逻辑。
- **适应性强**: 能够根据是否支持视觉或是否配置MCP等运行时条件，动态调整其能力描述。
- **可定制性**: 允许通过自定义行为规则文件来修改代理的默认行为，以满足特定需求。
