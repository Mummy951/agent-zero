# 贡献 Agent Zero

非常欢迎为改进 Agent Zero 做出贡献！本指南概述了如何贡献代码、文档或其他改进。

## 开始

1. **派生仓库：** 在 GitHub 上派生 Agent Zero 仓库。
2. **克隆您的派生：** 将您派生出来的仓库克隆到您的本地机器。
3. **创建分支：** 为您的更改创建一个新分支。使用一个描述性的名称，以反映您贡献的目的（例如，`fix-memory-leak`、`add-search-tool`、`improve-docs`）。

## 进行更改

* **代码风格：** 遵循现有的代码风格。Agent Zero 通常遵循 PEP 8 约定。
* **文档：** 如果您的更改影响面向用户的功能，请更新文档。文档以 Markdown 编写。
* **提交消息：** 编写清晰简洁的提交消息，解释您更改的目的。

## 提交拉取请求

1. **推送您的分支：** 将您的分支推送到您在 GitHub 上的派生仓库。
2. **创建拉取请求：** 从您的分支向 Agent Zero 主仓库的适当分支创建拉取请求。
   * 目标分支为 `development`。
3. **提供详细信息：** 在您的拉取请求描述中，清楚地解释您更改的目的和范围。包括相关上下文、测试结果以及对审阅者可能有用的任何其他信息。
4. **处理反馈：** 积极回应社区的反馈。我们喜欢更改，但也喜欢讨论它们！

## 文档技术栈

- 文档使用 Markdown 构建。即使您不了解 Markdown，我们也感谢您的贡献，并期待为每个人的利益改进 Agent Zero。
