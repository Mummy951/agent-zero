# 使用指南
本指南探讨了 Agent Zero 的使用和配置场景。您可以将其视为安装后的参考指南。

![带有解决方案的实用消息](res/memory-man.png)

## 基本操作
Agent Zero 通过其界面提供了几个基本操作：

### 重启框架
“重启”按钮允许您无需使用终端即可快速重启 Agent Zero 框架：

![重启框架](res/ui-restarting.png)

* 点击侧边栏中的“重启”按钮
* 将出现一个蓝色通知，指示“正在重启...”
* 完成后，将显示一个绿色的成功消息“已重启”
* 框架将重新初始化，同时保留您当前的聊天历史和上下文

> [!TIP]
> 当您想执行以下操作时，请使用重启功能：
> - 如果遇到意外行为，请重置框架
> - 当代理无响应时，重新初始化系统

### 操作按钮
Agent Zero 在聊天输入框下方提供了一组操作按钮，用于增强控制和可见性：

![操作按钮](res/ui-actions.png)
#### 聊天流控制
* **暂停/恢复代理：** 切换按钮以暂停和恢复聊天流
  - 点击可暂停正在进行的代理操作
  - 暂停时变为“恢复代理”
  - 再次点击可恢复聊天流和命令执行

#### 知识和文件管理
* **导入知识：** 将外部文件导入代理的知识库
  - 支持 `.txt`、`.pdf`、`.csv`、`.html`、`.json` 和 `.md` 格式
  - 文件存储在 `\knowledge\custom\main` 中
  - 成功消息确认成功导入
  - 有关更多详细信息，请参阅 [知识](architecture.md#knowledge)

### 文件浏览器：管理 Agent Zero 环境中的文件
  - 上传新文件和文件夹
  - 下载文件（点击文件名）或文件夹（作为 zip 存档）
  - 删除文件和文件夹
  - 使用“向上”按钮导航目录
  - 即将支持文件重命名和搜索
  - 有关详细功能，请参阅 [文件浏览器](#file-browser) 部分

#### 调试和监控
* **上下文：** 查看发送到 LLM 的完整上下文窗口
  - 包括系统提示
  - 显示当前对话上下文
  - 显示活动指令和参数

![上下文](res/ui-context.png)

### 历史记录：
以 JSON 格式访问聊天历史记录
  - 查看 LLM 处理后的对话
  - 有助于调试和理解代理行为

![历史记录](res/ui-history.png)

* **提示：** 重新启动代理的上次进程
  - 当代理无响应时很有用
  - 重试上次操作
  - 有助于从卡住的状态中恢复

![提示](res/ui-nudge.png)

> [!TIP]
> 使用“上下文”和“历史记录”按钮来理解代理如何解释您的指令，并调试任何意外行为。

### 文件附件
Agent Zero 支持在聊天界面中直接附件文件，以实现无缝的文件操作：

#### 附件文件
* 点击聊天输入框左侧的附件图标 (📎)
* 选择一个或多个文件进行附件
* 发送前预览附件文件：
  - 文件名及其类型（HTML、PDF、JPG 等）会显示
  - 如果有缩略图，图像会显示缩略图
  - 文件会列在聊天输入区域中，等待发送

![文件附件](res/ui-attachments.png)

#### 处理附件文件
* 文件可以直接在您的消息中引用
* Agent Zero 可以：
  - 处理附件文件
  - 将文件移动到特定目录
  - 同时对多个文件执行操作
  - 通过详细响应确认成功的文件操作

![处理附件](res/ui-attachments-2.png)

> [!TIP]
> 当处理多个文件时，您可以一次性全部附件，然后给出有关如何处理它们的指令。代理将批量处理它们，同时让您了解进度。

## 工具使用
Agent Zero 的强大之处在于其使用 [工具](architecture.md#tools) 的能力。以下是如何有效利用它们：

- **理解工具：** Agent Zero 包括默认工具，如知识（由 SearXNG 提供支持）、网页内容、代码执行和通信。了解这些工具的功能以及如何调用它们。

## 工具使用示例：网络搜索和代码执行
假设您希望 Agent Zero 执行一些财务分析任务。以下是一个可能的提示：

> 请您作为一名专业的财务分析师。查找上个月比特币/美元的价格趋势，并在您的环境中制作图表。图表必须突出显示与加密货币重大新闻日期对应的关键点。使用“knowledge_tool”查找价格和新闻，并使用“code_execution_tool”执行其余任务。

Agent Zero 可能会：

1. 使用 `knowledge_tool` 查询可靠来源以获取比特币价格和加密货币新闻，如提示中所述。
2. 从搜索结果中提取价格并保存新闻，提取其日期和对价格的可能影响。
3. 使用 `code_execution_tool` 执行一个 Python 脚本，该脚本使用提取的数据和新闻日期作为输入来创建图表并突出显示关键点。
4. 返回最终图表，您将在 `/work_dir` 中找到它，并使用 `response_tool` 回复用户。

> [!NOTE]
> 第一次运行 `code_execution_tool` 可能需要一段时间，因为它会下载并构建 Agent Zero Docker 镜像。后续运行将更快。

此示例演示了如何结合多个工具来完成分析任务。通过掌握提示工程和工具使用，您可以释放 Agent Zero 的全部潜力来解决复杂问题。

## 多代理协作
多代理协作是 Agent Zero 的独特功能之一。

* **创建子代理：** 代理可以创建子代理来委托子任务。这有助于管理复杂性并分配工作负载。
* **通信：** 代理之间可以相互通信，共享信息和协调行动。系统提示和消息历史在指导这种通信中起着关键作用。
* **层次结构：** Agent Zero 使用 [分层结构](architecture.md#agent-hierarchy-and-communication)，上级代理将任务委托给下属代理。这允许结构化的问题解决和高效的资源分配。

## 提示工程
有效的提示工程对于充分利用 Agent Zero 至关重要。以下是一些技巧和技术：

* **清晰具体：** 清楚地说明您想要的结果。您越具体，Agent Zero 就能越好地理解并满足您的请求。避免模糊或模棱两可的语言。
* **提供上下文：** 如有必要，提供背景信息或上下文，以帮助代理更好地理解任务。这可能包括相关细节、约束或所需响应格式。
* **分解复杂任务：** 对于复杂任务，将其分解为更小、更易于管理的子任务。这使得代理更容易推理问题并生成解决方案。
* **迭代优化：** 不要期望第一次就得到完美的结果。尝试不同的提示，根据代理的响应优化您的指令，并迭代直到达到所需的结果。例如，要完成一个全栈 Web 应用程序开发任务，您可能需要迭代几个小时才能 100% 成功。

## 语音界面
Agent Zero 提供文本转语音 (TTS) 和语音转文本 (STT) 功能，以实现自然的语音交互：

### 文本转语音
启用代理的语音响应：
* 切换侧边栏“偏好设置”部分中的“语音”开关
* 代理将使用您系统内置的语音合成器来朗读其消息
* 点击输入区域上方的“停止语音”按钮可立即停止任何正在进行的语音

![TTS 停止语音](res/ui-tts-stop-speech.png)

- 如果响应过长或用户希望在对话中进行干预，界面允许用户随时停止语音。

TTS 使用现代浏览器提供的标准语音接口，它可能听起来有些机械化，但有效，并且不需要复杂的 AI 模型。这确保了跨各种平台（包括移动设备）的低延迟和快速响应。

> [!TIP]
> 文本转语音功能非常适合：
> - 在接收代理响应时进行多任务处理
> - 辅助功能用途
> - 创建更具交互性的体验

### 语音转文本
使用 OpenAI 的 Whisper 模型向代理发送语音消息（不需要 OpenAI API 密钥！）：

1. 点击输入区域中的麦克风按钮开始录音
2. 按钮颜色表示当前状态：
   - 灰色：不活动
   - 红色：正在收听
   - 绿色：正在录音
   - 青色：正在等待
   - 青色（脉冲）：正在处理

用户可以在发送前调整静音阈值和消息持续时间等设置，以优化其交互体验。

在“设置”页面配置 STT 设置：
* **模型大小：** 在基本模型（74M，英语）或其他模型之间选择
  - 注意：只有大型和 Turbo 模型支持多种语言
* **语言代码：** 设置您的首选语言（例如，'en'、'fr'、'it'、'cz'）
* **静音检测：**
  - 阈值：调整灵敏度（值越低越灵敏）
  - 持续时间：设置录音结束前静音应持续多长时间
  - 超时：设置关闭麦克风前的最长等待时间

![语音转文本设置](res/ui-settings-5-speech-to-text.png)

> [!IMPORTANT]
> 所有 STT 和 TTS 功能都在 Docker 容器中本地运行，
> 确保没有数据传输到外部服务器或 OpenAI API。这
> 在保持功能的同时增强了用户隐私。

### 数学表达式
Agent Zero 支持 KaTeX 以实现美观的数学排版：

* **行内数学：** 使用单个美元符号 `$...$` 表示行内表达式
  - 示例：输入 `圆的面积是 $A = πr^2$`
  - 渲染为：圆的面积是 $A = πr^2$

* **显示数学：** 使用双美元符号 `$$...$$` 表示居中显示方程
  - 示例：输入 `$$F = Grac{m_1m_2}{r^2}$$`
  - 渲染为居中方程

![KaTeX](res/ui-katex-1.png)

* **复杂数学：** 支持 KaTeX 的完整语法，包括：
  - 分数、指数和根
  - 矩阵和数组
  - 希腊字母和数学符号
  - 积分、求和和极限
  - 数学对齐和方程

![KaTeX 显示](res/ui-katex-2.png)

> [!TIP]
> 当要求代理解决数学问题时，它将自动使用 KaTeX 格式进行响应，以获得清晰专业的数学表达式。

### 文件浏览器
Agent Zero 提供了一个强大的文件浏览器界面，用于管理您的工作区：

#### 界面概览
- **导航栏**：显示当前目录路径，带有用于父目录的“向上”按钮
- **文件列表**：显示文件和目录，并附有关键信息：
  - 名称（可排序）
  - 大小（字节）
  - 上次修改时间戳
- **操作图标**：每个文件/目录都有：
  - 下载按钮
  - 删除按钮（带确认）

![文件浏览器](res/ui-file-browser.png)

#### 功能
- **目录导航**：
  - 点击目录进入
  - 使用“向上”按钮移动到父目录
  - 当前路径始终可见，以便于上下文

> [!NOTE]
> 文件浏览器允许用户点击“向上”按钮进入 Agent Zero 根文件夹，但代理的工作目录始终是 `/work_dir`

- **文件操作**：
  - 创建新文件和目录
  - 删除现有文件和目录
  - 将文件下载到本地系统
  - 从本地系统上传文件
- **文件信息**：
  - 文件类型（文件夹、代码文件、文档）的视觉指示器
  - 人类可读格式的大小信息
  - 上次修改时间戳
- **批量操作**：
  - 同时上传多个文件
  - 一次选择和管理多个文件

> [!TIP]
> 文件浏览器与 Agent Zero 的功能无缝集成。您可以在对话中直接引用文件，代理可以帮助您管理、修改和组织文件。

## 备份与恢复
Agent Zero 提供了全面的备份和恢复系统，以保护您的数据和配置。此功能可帮助您保护您的工作并将 Agent Zero 设置在不同系统之间迁移。

### 创建备份
通过“设置”界面访问备份功能：

1. 点击侧边栏中的 **“设置”** 按钮
2. 导航到 **“备份”** 选项卡
3. 点击 **“创建备份”** 开始备份过程

#### 备份内容
默认情况下，Agent Zero 会备份您最重要的数据：

* **知识库**：您的自定义知识文件和文档
* **内存系统**：代理记忆和学习信息
* **聊天历史**：您的所有对话和交互
* **配置文件**：设置、API 密钥和系统偏好设置
* **自定义仪器**：您添加或修改的任何工具
* **上传文件**：您处理过的文档和文件

#### 自定义备份内容
在创建备份之前，您可以自定义要包含的内容：

* **编辑模式**：使用内置编辑器精确指定要备份的文件和文件夹
* **包含隐藏文件**：选择是否包含系统和配置文件
* **预览文件**：查看在创建备份之前将包含哪些内容
* **有组织视图**：文件按目录分组，便于查看

> [!TIP]
> 备份系统使用模式匹配，因此您可以包含或排除特定文件类型。
> 例如，您可以备份所有 `.py` 文件，但排除临时 `.tmp` 文件。

#### 创建备份
1. 查看文件预览，确保您正在备份所需内容
2. 给您的备份一个描述性名称
3. 点击 **“创建备份”** 生成存档
4. 备份文件将自动下载为 ZIP 存档

> [!NOTE]
> 备份创建可能需要几分钟，具体取决于数据量。您将在过程中看到进度更新。

### 从备份恢复
恢复过程允许您从以前的备份中恢复 Agent Zero 设置：

#### 开始恢复
1. 导航到 **“设置”** → **“备份”** 选项卡
2. 点击 **“从备份恢复”**
3. 上传您的备份 ZIP 文件

#### 恢复前审核
上传后，您可以审核和自定义恢复：

* **检查元数据**：查看有关备份创建时间和地点的信息
* **编辑恢复模式**：精确选择要恢复的文件
* **预览更改**：查看哪些文件将被恢复、覆盖或跳过
* **跨系统兼容性**：在不同系统上恢复时，路径会自动调整

#### 恢复选项
配置恢复应如何处理现有文件：

* **覆盖**：用备份版本替换现有文件
* **跳过**：保留现有文件，只恢复缺失的文件
* **备份现有文件**：在覆盖之前创建现有文件的备份副本

#### 恢复前清理
选择性地在恢复前清理现有文件：

* **智能清理**：在恢复前删除与备份模式匹配的文件
* **预览清理**：在确认前查看将删除哪些文件
* **安全操作**：仅影响与您指定模式匹配的文件

### 最佳实践

#### 何时创建备份
* **重大更改之前**：在重大修改之前始终备份
* **定期计划**：每周或每月备份您的工作
* **系统更新之前**：在更新 Agent Zero 或系统组件之前备份
* **项目里程碑**：在完成重要工作时保存备份

#### 备份管理
* **描述性名称**：使用清晰的名称，如“project-completion-2024-01”
* **外部存储**：将备份文件保存在 Agent Zero 之外的安全位置
* **多个版本**：保留多个备份版本以用于不同时间段
* **测试恢复**：偶尔测试恢复备份，以确保它们正常工作

#### 安全注意事项
* **API 密钥**：备份包含您的 API 密钥和敏感配置
* **安全存储**：安全存储备份文件，不要共享
* **清理系统**：在恢复到新系统时，验证所有配置

### 常见用例

#### 系统迁移
将 Agent Zero 移动到新服务器或计算机：
1. 在原始系统上创建完整备份
2. 在新系统上安装 Agent Zero
3. 恢复备份以迁移所有数据和设置

#### 项目归档
保存已完成的项目：
1. 创建项目特定的备份模式
2. 仅包含相关文件和对话
3. 将备份存储为项目存档

#### 开发快照
保存正在进行的工作状态：
1. 在开发过程中频繁创建备份
2. 使用描述性名称跟踪进度
3. 如果出现问题，恢复以前的版本

#### 团队协作
共享 Agent Zero 配置：
1. 创建包含共享配置和工具的备份
2. 团队成员可以恢复以获得一致的设置
3. 包括文档和项目文件

> [!IMPORTANT]
> 在依赖备份进行关键数据恢复之前，请务必在安全环境中测试您的备份和恢复过程。
> 保留多个备份版本，并将它们存储在安全、可访问的位置。

> [!TIP]
> 备份系统旨在跨不同操作系统和 Agent Zero 安装工作。
> 您在 Windows 系统上创建的备份将在 Linux 上工作，反之亦然。
