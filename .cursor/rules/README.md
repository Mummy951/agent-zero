# Agent-Zero Cursor Rules 说明

本目录包含为 Agent-Zero 项目定制的 Cursor 规则集合，旨在帮助开发者更好地理解项目架构和遵循开发最佳实践。

## 规则文件概览

### 核心架构规则
- **`project-architecture.mdc`** - 项目整体架构指南（始终应用）
  - 核心入口点和目录结构
  - 开发工作流概述
  - 关键组件说明

### 开发指南规则
- **`api-development.mdc`** - REST API 端点开发
- **`frontend-development.mdc`** - Web UI 前端开发
- **`tools-development.mdc`** - AI 代理工具开发
- **`extensions-development.mdc`** - 扩展系统开发
- **`prompts-management.mdc`** - 提示和角色管理

### 部署和集成规则  
- **`docker-deployment.mdc`** - Docker 容器化部署
- **`mcp-integration.mdc`** - MCP 协议集成开发

### 质量保证规则
- **`code-style.mdc`** - 代码风格和开发准则
- **`testing-quality.mdc`** - 测试和质量保证
- **`development-workflow.mdc`** - 开发工作流和最佳实践

## 规则应用范围

### 始终应用的规则
- **项目架构指南** - 对所有文件生效

### 基于文件类型的规则
- **Python 文件** (`python/**/*.py`)
  - API 开发规则
  - 工具开发规则  
  - 扩展开发规则
  - 测试规则
  - 代码风格规则

- **前端文件** (`webui/**/*`)
  - 前端开发规则
  - 代码风格规则

- **配置文件** (`docker/**/*`, `prompts/**/*.md`)
  - Docker 部署规则
  - 提示管理规则

### 手动应用的规则
- **MCP 集成指南** - 在开发 MCP 相关功能时使用
- **开发工作流** - 项目管理和协作时参考

## 如何使用这些规则

1. **项目架构规则**会自动应用到所有编辑活动中
2. **文件类型规则**会根据当前编辑的文件自动激活
3. **描述性规则**可以通过 Cursor 的规则搜索功能手动调用
4. 在开发特定功能时，可以主动引用相关规则文档

## 规则维护

当项目架构或开发流程发生变化时，请及时更新相应的规则文件：

- 新增功能模块时更新架构规则
- 修改 API 接口时更新 API 开发规则  
- 变更部署方式时更新 Docker 规则
- 调整代码风格时更新风格规则

## 贡献指南

如果您发现规则有遗漏或需要改进的地方，请：

1. 修改对应的 `.mdc` 文件
2. 确保规则的元数据配置正确
3. 测试规则在实际开发中的效果
4. 提交更新以供团队使用
