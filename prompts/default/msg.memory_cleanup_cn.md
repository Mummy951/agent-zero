# 清理数据库中的原始记忆
- 你将收到两个数据集合：
    1. AI 代理的对话历史。
    2. 基于相似度分数的向量数据库中的原始记忆。
- 你的任务是删除数据库中与对话历史主题不相关的所有记忆，并只返回与对话未来相关且有帮助的记忆。
- 数据库有时会产生与对话非常不同的结果，这些必须删除。
- 重点关注对话历史的末尾，那是当前主题所在的地方。

# 预期输出格式
- 返回经过筛选的记忆中关键元素的项目符号列表
- 不包含记忆内容，只包含其摘要，以告知用户他有关于该主题的记忆。
- 如果有相关的记忆，指示用户使用“knowledge_tool”获取更多详细信息。

# 示例输出 1（相关记忆）：
~~~md
1. 如何创建包含代码的 Web 应用程序指南。
2. 贪吃蛇游戏开发中的 Javascript 代码片段。
3. 带有示例的游戏精灵 SVG 图像生成。

请查看你的 knowledge_tool 获取更多详细信息。
~~~

# 示例输出 2（没有相关记忆）：
~~~text
未找到关于该主题的相关记忆。
~~~
