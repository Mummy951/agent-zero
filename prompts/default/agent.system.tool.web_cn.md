### webpage_content_tool:
获取网页文本内容，如新闻、维基等
使用 `url` 参数获取主要文本
收集在线内容
提供带有 http:// 或 https:// 的完整有效 URL

**使用示例**:
```json
{
    "thoughts": [
        "...",
    ],
    "headline": "提取网页文本内容",
    "tool_name": "webpage_content_tool",
    "tool_args": {
        "url": "https://...comexample",
    }
}
```
