# memory 功能说明

## 提示词文件列表及功能

- [`memory.memories_query.sys.md`](prompts/default/memory.memories_query.sys.md): 记忆查询系统相关的英文提示。
- [`memory.memories_sum.sys.md`](prompts/default/memory.memories_sum.sys.md): 记忆总结系统相关的英文提示。
- [`memory.solutions_query.sys.md`](prompts/default/memory.solutions_query.sys.md): 解决方案查询系统相关的英文提示。
- [`memory.solutions_sum.sys.md`](prompts/default/memory.solutions_sum.sys.md): 解决方案总结系统相关的英文提示。

## 功能总结

这类提示词用于代理的记忆管理，包括记忆的查询和总结，以及解决方案的查询和总结。它们帮助代理有效地存储、检索和利用历史信息和解决方案。
